## Data Manipulation Program

# This is a data manipulation program for the csv file that comes in the repository. This was my first time using pandas, NumPy, and matplotlib and it was a great first program.

## Features:
-Good Main Menu
# Functions
-Average CPU price
-Lowest CPU price
-Highest CPU price
-Number of Intel CPUs
-Number of AMD CPUs
-Average price of Intel CPUs
-Average price of AMD CPUs
-Price Filter
-Standard Deviation of data set
-CPU Architecture vs Price graph
-CPU Cores vs Price graph

## How to run

Run:

```bash
python data_manipulation.py
```
